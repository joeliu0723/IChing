# Product Goal

Project IChing 是一套本機運行的**易經研究工作台**。

定位不是算命軟體，而是提供起卦、解卦、占卜紀錄與知識整理的平台。

主要用途：

- 起卦／排卦
- 解卦閱讀與研究
- 保存研究紀錄
- 查詢、排序、編輯歷史紀錄
- 事後驗證占卜結果
- 編輯 64 卦解卦資料（Data Editor）

所有資料均保存於本機（Local First）。

# 起卦頁

功能：建立新的占卜，完成後進入解卦頁。排卦結果先存在 session；解卦頁按「儲存問題」才寫入 `history.json`。

## 基本資料

- 占卜問題（`editQuestion`）
- 姓名／性別／年齡：**規格有、目前 UI 未完整實作**

## 輸入模式

以 RadioButton 切換，僅顯示目前模式（`QStackedWidget` 固定區域，避免跳動）。

| 模式 | 狀態 |
|------|------|
| 六爻輸入 | ✓ 已完成 |
| 卦名輸入 | ✓ 已完成 |
| 卦序輸入 | ✓ 已完成 |
| 上下卦輸入 | ✓ 已完成 |
| 數字卦（梅花易數三數） | ✓ 已完成（V1.4.12） |

所有方式最後皆走同一套流程：Controller → HexagramEngine → Presenter → 解卦頁。

排卦觸發：**「開始解卦」按鈕**（六爻選滿不會自動排卦）。

### 六爻輸入

由下而上六列；每列少陽／少陰／老陽／老陰（互斥）。

### 數字卦（梅花易數）

填寫三組正整數：

- 第1數 → 上卦（÷8 餘，餘0作8）
- 第2數 → 下卦（÷8 餘，餘0作8）
- 第3數 → 動爻（÷6 餘，餘0作6；1=初…6=上）

先天八卦序：1乾 2兌 3離 4震 5巽 6坎 7艮 8坤。

### 排卦結果（起卦頁摘要）

- 本卦：卦序、卦名
- 變卦：卦序、卦名
- 動爻列表

# 解卦頁

顯示本次占卜完整資訊；多數經文區塊為**可折疊**（預設折疊）。

## 已實作顯示／編輯

| 項目 | 說明 | 狀態 |
|------|------|------|
| 占卜問題 | 可編輯並「儲存問題」 | ✓ |
| 收藏 | Checkbox，即時寫入 | ✓ |
| 本卦／變卦／動爻 | 標籤顯示 | ✓ |
| 卦辭 | 本卦 | ✓ |
| 大帥解釋 | 對應資料欄 `tuan`（顯示名；原稱彖傳） | ✓ |
| 象傳／文言 | 本卦 | ✓（資料可空） |
| 白話翻譯 | 本卦；缺資料時可 fallback description | ✓ |
| 變卦卦辭／大帥解釋／象傳／文言／白話翻譯 | | ✓ |
| 爻辭 | 含動爻標記；缺原文時顯示陰陽 | ✓ |
| AI 分析 | UI 占位，**尚未串接** | □ |
| 我的心得 | 可編輯＋「儲存心得」 | ✓ |
| 事後驗證 | 驗證結果下拉＋驗證內容＋儲存 | ✓ |

驗證結果固定：未驗證／符合／部分符合／不符合。

# Data Editor（獨立工具）

用途：編輯 64 卦解卦資料（`hexagrams.json`）。

啟動：

```
python -m tools.data_editor
```

| 功能 | 狀態 |
|------|------|
| 選卦編輯卦辭／大帥解釋／象傳／文言／白話／爻辭 | ✓ |
| 儲存／重載／備份 | ✓ |
| 右側捲動 | ✓ |
| 語音輸入（Windows Win+H／中文台灣） | ✓ |
| 依欄位批次匯入 | 已實作但 UI 暫隱藏 |

開發時資料路徑：專案 `data/`。  
打包後：`%APPDATA%\IChing\data\`（首次從 `_internal/data/hexagrams.json` 複製）。可攜資料夾／zip：`packaging/build_exes.ps1`。Inno 安裝程式草稿在 `packaging/iching.iss`，正式發行驗證仍可暫緩。

# 目前進度總覽（截至 2026-08-10）

**現行版本：V1.4.12**

狀態：Active Development — 核心起卦／解卦／歷史／Data Editor 已可用；AI 與安裝包暫緩。

## 已完成（濃縮）

1. **架構**：Python 3.13 + PySide6 + MVC + JSON Local First  
2. **起卦**：六爻、卦名、卦序、上下卦、數字卦（梅花三數）；「開始解卦」  
3. **解卦**：本／變卦經文、爻辭、折疊 UX、心得、驗證、收藏、問題編輯  
4. **歷史**：自動存檔、搜尋、排序升降、多選刪除、雙擊開啟  
5. **工具**：獨立 Data Editor（捲動、Win+H 語音）  
6. **資料路徑**：`core/paths.py`（開發用專案 `data/`）

## 進行中／暫緩

- 進行中：以 Data Editor 補齊 64 卦內容  
- 暫緩：Windows 安裝包、V1.5 AI  
- 未做：設定頁、備份／還原 ZIP、匯出 PDF／Word  

啟動主程式：`python main.py`  
啟動 Data Editor：`python -m tools.data_editor`

# V0.1 - 專案建立

日期：2026-07

## 完成項目

- 確立專案名稱：Project IChing（易經研究工作台）
- 確立 V1.0 開發目標
- 採用 Local First 架構
- 決定使用 JSON 作為唯一資料儲存格式
- 不使用 SQL Database
- 不使用 ORM
- 確立 Python 3.13 為開發語言
- 採用 PySide6 作為 GUI Framework
- 採用 Qt Designer 設計 UI
- 建立專案目錄規劃
- 建立文件架構
